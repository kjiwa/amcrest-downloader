# Security

amcrest-downloader reads camera credentials from command-line flags, environment
variables, or an interactive prompt. It connects only to the camera you configure,
and writes only to the output directory and the optional log file. It sends no
telemetry.

## Reporting a vulnerability

Please use
[GitHub's private vulnerability reporting](https://github.com/kjiwa/amcrest-downloader/security/advisories/new)
for this repository rather than opening a public issue. If that option isn't
available yet, email kamil.jiwa@gmail.com instead.
